# Customer-Shopping-Behavior-Analysis
Raw Dataset → Python (EDA & Cleaning) → PostgreSQL (SQL Analysis) → Power BI (Interactive Dashboard) → Business Insights
## 📌 Project Overview
This project focuses on analyzing customer shopping behavior to uncover meaningful business insights, identify purchasing patterns, and understand customer preferences.
It follows an end-to-end data analytics workflow using **Python, PostgreSQL, and Power BI**, transforming raw customer shopping data into actionable insights through data exploration, cleaning, SQL analysis, and interactive visualization.

## 🎯 Project Objectives
- Explore and understand customer shopping behavior.
- Perform Exploratory Data Analysis (EDA) to identify patterns and trends.
- Clean and preprocess raw data to ensure data quality.
- Use PostgreSQL to perform SQL queries and answer business questions.
- Develop an interactive Power BI dashboard to visualize key metrics.
- Generate actionable insights to support business decision-making.

## 🛠️ Tools & Technologies
Python | Data loading, EDA, cleaning, and preprocessing 
Pandas | Data manipulation and transformation 
VS Code | Python development and analysis 
PostgreSQL | Database management and SQL analysis 
SQL | Business queries and insight generation 
Power BI | Interactive dashboard and data visualization

## 🔄 Project Workflow
### 1. Data Loading & Exploration – Python
- Imported the customer shopping dataset into Python.
- Used Pandas to inspect the dataset structure.
- Examined columns, data types, and dataset dimensions.
- Identified missing values, duplicate records, and inconsistencies.

### 2. Exploratory Data Analysis (EDA)
- Analyzed customer demographics and shopping patterns.
- Explored purchasing behavior and product preferences.
- Identified trends and relationships within the dataset.
- Used statistical summaries to understand the data.

### 3. Data Cleaning & Preprocessing – Python
- Handled missing and inconsistent values.
- Removed duplicate records where necessary.
- Corrected data types and formatting issues.
- Created and transformed columns for further analysis.
- Prepared a clean dataset for PostgreSQL analysis.

### 4. SQL Analysis – PostgreSQL
- Loaded the cleaned dataset into PostgreSQL.
- Performed SQL queries to answer business-related questions.
- Used filtering, aggregation, grouping, and joins where applicable.
- Analyzed customer purchasing patterns and product performance.
- Extracted meaningful business insights from the data.

### 5. Interactive Dashboard – Power BI
- Connected Power BI to the analyzed dataset.
- Developed an interactive dashboard.
- Created visualizations to highlight important business metrics.
- Presented customer behavior, purchasing trends, and key insights.
- Designed an intuitive dashboard to support data-driven decisions.
